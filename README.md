# TIDE Kitchen — Website

A static editorial site for TIDE Kitchen — South Shore, Chicago. Opening 2027.

## Structure

```
index.html          the main single-page site (HTML, CSS, JS in one file)
request.html        request form
partner.html        partnership inquiry form
community.html      community list form
assets/img/         photographs and renderings
```

No documents are stored in this repository. Forms post to Google Apps Script endpoints set in each
page's `<form action="…">`.

Nothing on this site is an offer to sell, or a solicitation of an offer to buy, any security.
